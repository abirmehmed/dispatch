# Dispatch

## What it does
Dispatch is a self-hosted, zero-dependency "link-in-bio" and announcement hub. It replaces third-party services like Linktree. 

You own the data. No ads, no analytics paywalls, no algorithmic suppression. It gives you a single, clean URL to broadcast petitions, articles, donation links, and updates directly to your audience.

## Features
- Pure PHP + JSON (No database, no composer, no frameworks)
- Password-protected admin panel
- CRUD operations (Add, Edit, Delete, Reorder)
- Clean, responsive UI
